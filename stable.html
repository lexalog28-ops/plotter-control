Плоттер: X/Y и серво

Не подключено · версия 5

Движение кареток

Удерживайте кнопку для движения. Отпустите для остановки.

Расчёт для 200 шагов/оборот без перемычек микрошагов. Начните с 30 об/мин. Ограничители хода не подключены.

Сервопривод


D12 / SpnEn. Углы нужно откалибровать под механизм. При подключении серво не двигается автоматически. Питание — отдельные 5 В, общая GND.

Нарисовать круг



Текущее положение ручки — центр. Нужен свободный радиус половины диаметра во все стороны. Сначала задайте шагов/мм обеих осей и проверьте углы «Вверх»/«Вниз». Для прямого привода GT2 16T без микрошагов: 200/(2×16) = 6,25 шагов/мм. При дополнительной передаче значение другое. Настройки сохраняются в этом браузере.

Журнал соединения
Откройте в Chrome или Edge на компьютере. Закройте монитор порта Arduino IDE. Нужна прошивка PLOTTER 5.
